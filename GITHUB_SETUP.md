# GitHub setup

## Create the repository

Create an empty GitHub repository (no README, license, or .gitignore generated by GitHub) and copy its `OWNER/REPO` path.

Then from the project root:

```bash
./scripts/publish-to-github.sh OWNER/REPO
```

The script initializes git if needed, commits the current code, sets `origin`, and pushes `main`.

## GitHub Actions configuration

After the first Terraform apply, create these repository variables:

- `AWS_REGION`
- `ECR_API_REPOSITORY`
- `ECR_FRONTEND_REPOSITORY`
- `ECS_CLUSTER`
- `ECS_SERVICE`

Create this repository secret:

- `AWS_DEPLOY_ROLE_ARN`

The value for each AWS-related item comes from Terraform outputs documented in `DEPLOYMENT.md`.

## Recommended repository settings

Enable branch protection for `main` and require the security CI workflow to pass before merging. Keep the deployment workflow restricted to `main` pushes.
